# Employee Performance Analysis – EDA Project

## Project Overview
This project focuses on analyzing employee data using Exploratory Data Analysis (EDA). The main goal is to understand employee performance, salary patterns, job satisfaction, and other important factors.

## Dataset Information
- **Dataset Name:** Employee Performance Analysis
- **Total Records:** 10,000
- **Total Columns:** 19
- **Data Type:** Synthetic Practice Dataset

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Objectives
- Analyze employee performance.
- Study department-wise employee distribution.
- Understand salary patterns across departments.
- Analyze the relationship between experience and salary.
- Explore employee satisfaction and overtime.
- Identify important patterns through data visualization.

## Data Cleaning
- Checked missing values.
- Handled missing values using mean, median, and mode where appropriate.
- Checked duplicate records.
- Prepared the dataset for analysis.

## Exploratory Data Analysis
The project includes 15 analysis activities and 5 selected visualizations, such as:

1. Employee Count by Department
2. Employee Performance Rating Distribution
3. Average Performance Score by Department
4. Correlation Analysis
5. Average Monthly Salary by Department

## Key Insights
- 49.90% of employees received an Average performance rating.
- Customer Support had the highest average department performance score.
- IT had the highest average monthly salary.
- Experience and monthly salary showed a positive correlation of 0.73.
- Average training time was approximately 3 hours per employee.

This project helped explore employee data and identify useful patterns related to performance, salary, experience, and job satisfaction.
